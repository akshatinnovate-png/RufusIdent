      Stored only in this browser. Anyone using this laptop's browser profile can read it. Move it to the backend before going live.

      Recognition runs on the backend (backend/server.py, usually http://localhost:8000). Its thresholds are calibrated from the students' own photos when you run enroll.py. Unsure matches go to “Needs review” on the gate screen, so a wrong student is never marked silently.

      Columns: admission_no, name, class, section, roll, house, photo. Header names are matched loosely (“Adm No”, “Student Name” work too). Importing replaces the current roster; attendance history is kept.
